Levantamento

Consulta de pedidos e devoluções — aponte a câmera para a etiqueta do pacote

Ler o número do pedido na etiqueta

Aponte para a etiqueta e enquadre a linha “Order ID: 702-…”. O app fotografa a tela, lê o texto e busca o pedido. Se a leitura falhar, use o botão de foto (maior resolução) ou digite o número.

A câmera exige página segura (HTTPS) — no GitHub Pages funciona automaticamente. A primeira leitura baixa o leitor de texto (uma vez só, uns 10 MB); depois o navegador costuma reaproveitar.

Ler código de barras / DataMatrix

Útil para as etiquetas dos pacotes de devolução (o código de barras “Código de Barras da devolução”, ex.: DY0wl3HFRRMA) e para rastreamentos (ex.: DA654782298BR). Na etiqueta de envio, o código de barras é de transporte e não contém o nº do pedido — para ela, use “Ler etiqueta”.

Digitar ou escolher

Aceita nº do pedido (702-…), rastreamento (…BR), código de postagem ou ID de devolução.
